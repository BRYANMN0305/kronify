# assets/ — Recursos estaticos

## Subdirectorios

- `styles/` — Hojas de estilo CSS globales
- `images/` — Imagenes del proyecto (iconos, fotos, logos)

## Estilos

El archivo principal es `styles/auth.css`, que define:

- **CSS variables** en `:root` con todos los colores del tema oscuro en HEX
- Estilos del layout de autenticacion (paneles, inputs, botones)
- Animaciones de slide entre formularios login/register
- Estilos de las barritas animadas del panel izquierdo
